Reports are research and public-health surveillance outputs. Genomic drug-resistance predictions and SNP linkage categories should not be used alone for clinical decisions or direct-transmission claims. Publish only reports approved for public sharing and remove identifiable patient information.

From sequencing data to surveillance interpretation

FASTQ / QC→ Kraken2→ MTBC / NTM routing→ TB-Profiler→ SNP / phylogeny→ HTML report

Not all analyses run on every sample. MTBC-specific tasks are conditional; non-MTBC samples are retained in species-routing summaries.

Report files and reproducibility

These examples are published as self-contained HTML files in two fixed locations:

docs/reports/panel1-mixtures/report.html docs/reports/panel2-mtbc-ntm/report.html

Report 1 contains 18 samples (all MTBC-routed); Report 2 contains 20 samples (14 MTBC and 6 non-MTBC). Source workflows and instructions are provided in the repository.
